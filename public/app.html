📲 เชื่อม LINE OA ของโรงแรม — ให้แขกจองห้องในแชท + รับแจ้งเตือน

แขกทัก LINE OA ของโรงแรม → เช็คห้องว่าง จอง และชำระเงินได้ในแชท · มีจองใหม่เด้งเข้า LINE ของคุณ (ทำครั้งเดียว ~5 นาที)

ใส่เมื่อ OA นี้มีระบบอื่นใช้อยู่ด้วย — Barn Park จะตอบเฉพาะเรื่องจอง (“ห้องว่าง” “จองห้อง” “การจองของฉัน” “จองกิจกรรม” ปุ่มของบอท และสลิปของการจองที่รอชำระ) ข้อความอื่นทั้งหมดส่งต่อไปที่ลิงก์นี้ให้ระบบเดิมตอบตามปกติ · เว้นว่าง = Barn Park ตอบทุกข้อความ

วิธีเชื่อม LINE OA ของโรงแรมคุณ (ทำครั้งเดียว):
1. ที่ developers.line.biz → เลือก Messaging API channel ของ OA โรงแรม → คัดลอก Channel secret (แท็บ Basic settings) + Channel access token (แท็บ Messaging API → Issue) มาวางด้านบน แล้วกดบันทึก
2. กด 🔌 ทดสอบและตั้งค่าอัตโนมัติ — ระบบตั้ง Webhook URL ให้ แล้วให้ LINE ลองส่งข้อความทดสอบ ถ้ามีขั้นไหนไม่ผ่านจะบอกวิธีแก้ (ส่วนใหญ่คือเปิดสวิตช์ Use webhook ในแท็บ Messaging API)
3. ลองแอดเพื่อน OA ของโรงแรมจากมือถือ แล้วพิมพ์ ห้องว่าง — บอทจะพาจองจนจบ
4. (รับแจ้งเตือนจองใหม่) แท็บ Basic settings → เลื่อนล่างสุด "Your user ID" (ขึ้นต้น U…) ก็อปมาวางช่อง "LINE ผู้รับแจ้งเตือน" → บันทึก · หรือพิมพ์ ไอดี ในแชท OA / ในกลุ่มของทีม
