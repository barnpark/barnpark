ใช้ LINE OA ของโรงแรมคุณเอง — มีจองใหม่/สรุปรายวันจะเด้งเข้า LINE ของคุณ (ทำครั้งเดียว ~5 นาที)

วิธีเชื่อม LINE OA ของโรงแรมคุณ (ทำครั้งเดียว):
1. ที่ developers.line.biz → สร้าง Messaging API channel ของโรงแรมคุณ → คัดลอก Channel access token + Channel secret มาวางด้านบน แล้วกดบันทึก
2. หา "ผู้รับแจ้งเตือน (userId)" — ง่ายสุด: ในหน้า channel → แท็บ Basic settings → เลื่อนล่างสุด เจอ "Your user ID" (ขึ้นต้น U…) ก็อปมาวางช่อง "LINE ผู้รับแจ้งเตือน" ด้านบน → บันทึก
3. แอดเพื่อน OA ของคุณเอง (สำคัญ! ไม่แอดเพื่อน LINE จะส่งหาไม่ได้) — เสร็จ! มีจองใหม่จะเด้งเข้า LINE ทันที
