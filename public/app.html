เชื่อม LINE OA ของโรงแรม (แจ้งเตือนเมื่อมีจองใหม่)

รับแจ้งเตือนเข้า LINE ของคุณเองทุกครั้งที่มีลูกค้าจอง — ตั้งค่าตามขั้นตอน

วิธีเชื่อม (ทำครั้งเดียว):
1. สร้าง Messaging API channel ที่ developers.line.biz → คัดลอก Channel access token + Channel secret มาวางด้านบน แล้วกดบันทึก
2. ในหน้า channel → ช่อง Webhook URL วางลิงก์นี้แล้วเปิด Use webhook:
3. เพิ่มเพื่อน OA ของคุณ แล้ว ทักข้อความอะไรก็ได้ → บอทจะตอบ userId ของคุณกลับมา
4. ก็อป userId นั้นมาวางช่อง "LINE ผู้รับแจ้งเตือน" แล้วกดบันทึกอีกครั้ง — เสร็จ! ต่อไปจะได้รับแจ้งเตือนทุกการจอง
