🌐 วิธีสมัคร OTA + เชื่อมกับ Barn Park

สำหรับเจ้าของที่พัก · อ่านจบแล้วรู้ว่าต้องทำอะไรบ้าง

เริ่มต้นเอกสารAgodaBooking.comAirbnbTrip.comส่ง ID ใน LINE

OTA คืออะไร ทำไมต้องเชื่อม

OTA = เว็บขายห้องออนไลน์ เช่น Agoda, Booking.com, Airbnb, Trip.com — ช่วยให้นักท่องเที่ยวเจอที่พักคุณมากขึ้น
ปัญหาคือถ้าขายหลายที่พร้อมกัน แล้วแต่ละที่ไม่รู้กัน → จองซ้อน (ห้องเดียวกันขายได้ 2 คน)
Barn Park จะซิงก์ห้องว่าง + ราคา ไปทุก OTA ให้อัตโนมัติ และดึงการจองกลับมาที่ปฏิทินเดียว
ลำดับง่าย ๆ: ① สมัคร OTA เอง (ฟรี) → ② ส่ง ID ให้ Barn Park ทาง LINE → ③ กดอนุญาตใน OTA → ทีมงานจับคู่ห้องให้ ✅
⏳ ระบบซิงก์ OTA อัตโนมัติกำลังเปิดให้บริการ — ส่งคำขอไว้ได้เลย ทีมงานจะติดต่อกลับเมื่อพร้อมเชื่อมให้ ระหว่างนี้ถ้ามีจองจาก OTA ให้กด 📅 การจอง → ➕ บันทึกการจองเอง ใน LINE เพื่อกันห้องบนเว็บ

📋 เตรียมเอกสารก่อนสมัคร

  • บัตรประชาชนเจ้าของ (หรือหนังสือรับรองบริษัท)
  • บัญชีธนาคาร ชื่อตรงกับเจ้าของ/บริษัท (ไว้รับเงิน)
  • เลขประจำตัวผู้เสียภาษี
  • ใบอนุญาตโรงแรม/หนังสือรับรองการแจ้ง (ถ้ามี)
  • ชื่อ + ที่อยู่ที่พัก ภาษาอังกฤษ + ปักหมุดแผนที่ให้ถูก
  • รูปสวย ๆ อย่างน้อย 10 รูป (ภายนอก ห้อง ห้องน้ำ วิว)
  • ข้อมูลห้อง: ประเภท จำนวน เตียง พักได้กี่คน ราคา
  • นโยบาย: เวลาเช็คอิน-เอาท์ การยกเลิก เด็ก อาหารเช้า สัตว์เลี้ยง
⚖️ ให้เช่ารายวัน/รายสัปดาห์ ถือเป็น “โรงแรม” ตามกฎหมาย ต้องมีใบอนุญาตหรือแจ้งที่จังหวัด และถ้ามีแขกต่างชาติ ต้องแจ้ง ตม. ภายใน 24 ชม. (ตม.30) — สอบถามอำเภอ/ทนายเพื่อความชัวร์

🅰️ Agoda

1
ค้นหา “Agoda list your property” → สมัคร (ฟรี) — ระบบหลังบ้านชื่อ Agoda Partner Portal (เดิมชื่อ YCS)
2
ใส่ข้อมูลที่พัก รูป ห้อง ราคา · ที่พักหลังเดียว/บ้านทั้งหลัง ให้สมัครแบบ Agoda Homes
3
Agoda ตรวจ ~3 วัน แล้วส่งสัญญาทางอีเมล → เซ็น
4
จด Agoda Hotel ID (ตัวเลขมุมบนของ Partner Portal) → ส่งใน LINE Barn Park
ตอนเชื่อม: Partner Portal → Property Settings → Optional Settings → Channel manager → เลือก Channex (ถ้าไม่เจอ ทักแชท Agoda ว่า “connect my property to Channex”)

🅱️ Booking.com

1
ไปที่ join.booking.com → List your property (ฟรี)
2
ใส่ข้อมูล ที่อยู่ รูป ห้อง ราคา นโยบาย
3
ยืนยันตัวตน + บัญชีรับเงิน + เลขภาษี (อาจมีจดหมายยืนยันส่งไปที่อยู่ที่พัก)
4
จด Property ID (ตัวเลขด้านบนหน้า Extranet) → ส่งใน LINE Barn Park
ตอนเชื่อม: Extranet → Account → Connectivity provider → ค้นหา Channex → เลือกและยอมรับ

🏠 Airbnb

1
airbnb.com → Airbnb your home → สร้างประกาศ (ห้อง รูป ราคา กฎบ้าน)
2
ยืนยันตัวตน + ใส่บัญชีรับเงิน → เปิดประกาศ
3
ก็อปลิงก์ประกาศ (airbnb.com/rooms/…) → ส่งใน LINE Barn Park
ตอนเชื่อม: ทีมงานจะส่งลิงก์ให้คุณล็อกอิน Airbnb ของคุณเองแล้วกดอนุญาต (ไม่ต้องบอกรหัสผ่านใคร) · Airbnb เชื่อมระบบได้ทีละ 1 ระบบ ถ้าเคยเชื่อมระบบอื่นต้องยกเลิกก่อน

✈️ Trip.com

1
ค้นหา “Trip.com list your property” → สร้างบัญชี eBooking (ฟรี)
2
กรอกชื่อ/ที่อยู่ภาษาอังกฤษ ประเภทที่พัก รูป ข้อมูลรับเงิน
3
เซ็นสัญญาออนไลน์ (ค่าคอมแสดงในขั้น Contract)
4
จด Hotel ID จากหน้า eBooking → ส่งใน LINE Barn Park
ตอนเชื่อม: ทีมงาน Barn Park จะประสานกับ Trip.com ให้

📲 ส่ง ID ให้ Barn Park ทาง LINE

1
เปิดแชท LINE Barn Park → กดเมนู 🌐 OTA
2
กด 🔗 ขอเชื่อม OTA → เลือก OTA → กด “มีแล้ว”
3
พิมพ์ ID (หรือวางลิงก์ Airbnb) → ทีมงานได้รับแจ้งทันที
4
ทำขั้น “ตอนเชื่อม” ของ OTA นั้น (กล่องสีเขียวด้านบน) แล้วรอทีมงานติดต่อกลับ
💡 หลังเชื่อมแล้ว ให้แก้ราคา/ปิดห้อง ที่ Barn Park ที่เดียว (ผ่าน LINE หรือเว็บหลังบ้าน) — ถ้าไปแก้ในหลังบ้าน OTA โดยตรง ระบบจะเขียนทับ

ค่าคอมมิชชันของแต่ละ OTA ดูได้ในสัญญาตอนสมัคร (สมัครฟรีทุกเจ้า จ่ายเมื่อมีคนจอง) · ขั้นตอน/เมนูของ OTA อาจเปลี่ยน ถ้าหาไม่เจอ ทักทีมงานใน LINE ได้เลย
