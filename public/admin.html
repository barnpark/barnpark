เช็กลิสต์ (ทำครั้งเดียว)

1. Render → Environment: LINE_CHANNEL_TOKEN, LINE_CHANNEL_SECRET, ADMIN_LINE_TO, SUPPORT_LINE_URL แล้ว Deploy
2. LINE Developers → channel Barn Park → Messaging API → Webhook URL = ลิงก์ด้านบน → Verify → เปิด Use webhook
3. LINE Official Account Manager → การตอบกลับ: เปิด Webhook · ปิด ข้อความตอบกลับอัตโนมัติ และ ข้อความทักทาย (บอทส่งให้เอง) · แชทเปิดไว้ได้ (คุยกับคนได้)
4. กดปุ่ม “ติดตั้งเมนู LINE” ด้านบน 1 ครั้ง
5. ทดสอบ: แอด LINE Barn Park → กด “สมัครที่พัก” → อนุมัติจากการ์ดที่เด้งมา → กด “เชื่อมเลย”

แจ้งอัปเดตระบบ + เช็กความครบ

เมื่อมีฟีเจอร์ใหม่ ส่งประกาศเข้า LINE Barn Park ของทุกคนที่เชื่อมที่พัก — แต่ละที่จะเห็นสิ่งที่ตัวเองยังขาด พร้อมปุ่มกดไปเพิ่มได้ทันที
